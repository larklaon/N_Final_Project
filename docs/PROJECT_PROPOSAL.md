# 틈지식 프로젝트 기획서

기준: 2026-10-19, Android V4 구현 상태. 이 문서는 실제 앱 저장소의 제출용 요약이며, 초기 개인 계획 문서를 복사한 것이 아니다.

## 문제와 대상

자격증 공부를 시작하려는 사람은 긴 학습 시간을 매일 확보하기 어렵다. 짧은 빈 시간에 기초 개념을 접하고, 막상 앱을 열었을 때 그 개념을 한 단계 깊은 문제로 연결할 방법이 필요하다. 학습 효과의 크기는 아직 측정하지 않았으므로 이 문서는 효과를 입증했다고 주장하지 않는다.

대상은 정보처리기사·SQLD를 준비하거나 기초를 다시 익히려는 Android 휴대폰 사용자다. 학습 목표가 뚜렷하지만 매번 공부를 시작하는 부담이 있는 사람을 첫 사용자로 가정한다.

## 해결 방식

틈지식은 두 층으로 학습을 제공한다.

1. **틈새 층:** 잠금 화면의 조용한 O/X 카드와 크기별 홈 위젯에서 짧은 문제를 제시한다. 사용자가 답한 결과를 기기에 남긴다. 카드 교체 간격과 방해 금지 시간을 설정할 수 있다.
2. **앱 층:** 앱에서 하루 3·5·10개의 상황형 문제를 풀고, 틈새에서 본 조각을 다시 확인한다. 개념별 해상도와 복습 일정이 기록에 따라 달라진다.
3. **선택형 AI:** 사용자가 ChatGPT를 연결하고 학습 정보 전송에 동의하면 개념 질문, 힌트, 해설, 7일 계획을 사용한다. 별도로 AI 맞춤 학습을 켜면 오답과 이 앱의 완료된 대화에서 헷갈린 점을 추출하고 짧은 카드를 생성한다.

초기 콘텐츠는 정보처리기사 기초 60개념과 SQLD 맛보기 12개념이다. 개념마다 틈새 카드 2개와 앱 문제 1개를 제공한다. 이 콘텐츠는 AI 작성 초안이며 모든 문장의 사실 정확성을 전문가가 검수한 상태는 아니다.

## AI를 쓰는 이유와 범위

단순 정답 판정, 해상도 계산, 복습 일정은 앱 코드가 처리한다. AI는 같은 개념을 헷갈려 하는 방식이 사람마다 다른 부분에 사용한다. 앱은 오답·관련 대화에서 근거가 있는 헷갈림을 저장하고 다음 카드·확인 문제·7일 계획에 재사용한다. 원문 대화 전체 대신 관련 요약만 전달한다.

AI가 생성한 카드는 승인된 기준 자료의 사실과 조건을 바탕으로 별도 검토를 통과한 경우에만 노출한다. 이 검토는 자동 검사이며 전문가 검수를 뜻하지 않는다. AI 생성 문제와 카드에는 `AI` 표시와 기준 자료 진입점이 있다.

과제의 두 기술 요소에 대응하는 구현은 다음과 같다.

| 요소 | 실제 구현 |
| --- | --- |
| Long-term Memory | SQLite에 학습자·과목·개념별 오답 근거와 헷갈림 상태를 보존하고, 이후 생성 카드·확인 문제·7일 계획에 활용한다. |
| 자동화 워크플로우 | 앱 기록 → AI 추출·생성·별도 검토 → Kotlin 카드 덱·위젯·잠금 화면 → 응답 이벤트 → SQLite 멱등 반영 → 확인 문제와 메모리 갱신으로 연결한다. |

앱이 백그라운드에서 AI를 계속 실행하지 않는다. 개인화 준비는 앱이 앞에 있고 동의·연결 조건이 맞을 때만 시작하며, 앱 밖 카드 표시는 준비된 덱으로 동작한다.

## 기술 선택과 구조

| 선택 | 이유 |
| --- | --- |
| React Native, Expo SDK 57, TypeScript | 학습 화면을 빠르게 구현하면서 Android 네이티브 기능은 로컬 Expo Module로 확장한다. |
| Kotlin `siwc-android` | Android 브라우저 인증 복귀, 로컬 HTTP 콜백, 토큰 보호, 공식 추론 응답 처리를 JS 밖에 둔다. |
| Kotlin `gap-android` | 앱이 열려 있지 않아도 잠금 화면 카드와 홈 위젯의 응답을 받아야 한다. |
| SQLite + 버전 있는 JSON 콘텐츠 | 오프라인 문제 이용과 학습 이력 보존, 중복 제출 방지, 스키마 마이그레이션에 적합하다. |
| SIWC | 사용자의 ChatGPT 연결을 통해 선택형 AI 기능을 제공한다. 계정·플랜의 실제 사용 가능 여부에 따라 AI 기능이 달라진다. |

구현 구조와 데이터 흐름은 [ARCHITECTURE](ARCHITECTURE.md), 기능·비기능 기준은 [REQUIREMENTS](REQUIREMENTS.md)에 기록한다. 앱 밖으로 학습 정보를 보내는 AI 기능에는 동의를 받고, 토큰은 Android Keystore로 보호한다.

## 일정과 현재 결과

| 단계 | 수행 시점 | 결과 |
| --- | --- | --- |
| 기반 앱·SIWC 최소 연동·오프라인 학습 | 2026-10-15~16 | 프로젝트, Kotlin 인증 모듈, 학습 기록과 기본 문제 구현 |
| 틈새 카드·위젯·화면 개편 | 2026-10-16~17 | 두 층의 응답 연결, 과목·퍼즐·AI 질문과 계획 구현 |
| 개인화 학습 V4와 검수 수정 | 2026-10-18~19 | 근거 메모리, 생성·검토, 확인 문제, 경계 결함 수정 |
| APK와 제출 자료 | 2026-10-19 | Metro 없이 실행하는 시연용 arm64 APK, V4 기획서·명세서·발표 자료 작성 |
| 외부 설치 경로와 배포 증빙 | 미완료 | APK가 로컬에 있으며 외부 다운로드 링크는 아직 없다. |

현재 APK는 **시연용**이다. 맞춤 학습의 대기 시간과 일일 한도를 줄였고 기본 채점·해상도·복습 계산은 그대로다. APK는 로컬에서 제작·설치해 실행했다. 정확한 빌드 결과와 검증 범위는 [BUILD](BUILD.md)와 [VERIFICATION](VERIFICATION.md)을 따른다.

## 범위와 한계

개인 프로젝트로 Android 휴대폰에 집중한다. 기본 학습은 오프라인에서 실행되고, AI는 연결 가능한 계정과 인터넷이 있을 때만 제공된다. 물리 기기별 잠금 화면·런처 차이, 신규 계정 인증 흐름, 전체 콘텐츠 사실 검수는 별도 확인이 필요하다. APK 외부 다운로드 링크는 아직 없다.
