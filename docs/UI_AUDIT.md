# UI 기능 점검 메모 — 2026-10-16

API36 에뮬레이터(412dp, 글씨 100%)에서 탭 4개와 학습 흐름(개념 → 퀴즈 → 오답 결과)을 직접 실행해 확인했다.

**V2.C4 처리:** 화면을 D안으로 새로 만들면서 P1-1(정답·오답이 선택지가 아니라 띠 안 정답 단어·취소선으로 표시), P1-2(앱이 문제 화면으로 시작, 출처는 개념 화면의 링크 행), P2-3(복습 탭과 원시 시각 표시 제거), P2-5(헤더 진행 표시), P3-6(헤더 중복 제거), P3-7(아이콘 + 문구), P3-8(라벨 체계)를 해소했다. P2-4(기록 화면)는 퍼즐 화면으로 대체했다.

## P1 — 학습 핵심 경험

1. **퀴즈 결과 표시 오류 소지**: 오답 제출 후에도 고른 선택지가 초록 강조(선택 상태)로 남아 정답처럼 보인다. 정답 선택지에는 표시가 없고 아래 본문 "정답: …"으로만 알린다. 제출 후 선택지 자체에 오답(빨강·✕)과 정답(초록·✓)을 표시해야 한다. 위치: `src/components/ui.tsx` `Choice`, `app/learn/[conceptId].tsx`.
2. **개념 화면 행동 위계**: '퀴즈 풀기'가 첫 화면 밖에 있다. 그 위의 같은 모양 보조 버튼 두 개 중 '기준 자료 · …'는 외부 링크인데 행동 버튼처럼 보인다.

## P2 — 정보 표현

3. **복습 예정 시각**: "2026. 10. 16. 오후 11:57:24"처럼 원시 시각을 표시한다. "오늘 밤 11시", "내일" 같은 상대 표현이 필요하다. 위치: `app/(tabs)/review.tsx`.
4. **기록 화면**: 7일 중 대부분이 0개 막대라 비어 보이고 `10-10` 날짜 형식이 딱딱하다. 표본 1개의 "정답률 100%"는 과장되어 보인다. 위치: `app/(tabs)/history.tsx`.
5. **오늘 목표**: `0 / 3개`가 텍스트뿐이고 진행을 보여 주는 시각 요소가 없다.

## P3 — 마감

6. **제목 중복**: 상단 바 "오늘" 아래에 큰 제목 "오늘의 틈지식"이 다시 나온다(복습·기록도 같음). 그림자 있는 기본 헤더가 제품 톤과 맞지 않는다.
7. **결과 메시지**: 색으로만 구분하고 아이콘이 없다. DESIGN.md의 "색상 + 아이콘·문구" 기준과 어긋난다.
8. **작은 라벨**: '짧은 퀴즈', 영역명 같은 섹션 라벨이 약해 구획이 잘 보이지 않는다.

전체 인상이 "AI가 만든 무난한 앱"에 가깝다는 피드백이 있었다. 개별 화면을 수정하기 전에 시각 방향부터 다시 정한다.
