## 0. 핵심 모델 (먼저 정하는 것)

**조각 = 개념.** 개념 60개가 퍼즐 조각 60개다(영역당 10개). 시안의 "20칸"은 10칸으로 바뀐다. 조각 하나는 세 상태를 가진다.

| 상태 | 조건 | 퍼즐 표시 |
| --- | --- | --- |
| 아직 | 틈새에서도 앱에서도 만나지 않음 | 옅은 칸 |
| 본 조각 | 틈새 카드에서 한 번 이상 답함 | 테두리 |
| 맞춘 조각 | 앱 문제를 채점 대상으로 맞힘 | 채움 |

**문제를 두 층으로 나눈다.**

- 틈새 카드: 기존 OX 60개 + 기존 객관식 60개를 그대로 쓴다. 지금 문제들이 이미 "보고 바로 넘길 수 있는" 난이도다.
- 앱 문제: **심화 객관식 60개를 새로 쓴다**(개념당 1개, 보기 4개). 상황을 주고 관련 개념을 엮어 생각하게 한다. 예: "학번이 기본키면 주민번호는?" 기존 콘텐츠와 같이 AI 작성 초안으로 표시한다.
- 심화 문제마다 `builtOn`(이 문제가 기대는 다른 개념 ID)을 둔다. 사용자가 그 개념을 틈새에서 봤다면 "잠금 화면에서 본 '후보키' 조각이 쓰였어요"를 보여 준다.

**기록 규칙.**

- 틈새 응답은 학습 기록에 남는다(`gap_events`). 오답이면 그 카드를 다음 날 다시 보여 주고, 정답이면 간격을 늘린다(1·3·7일).
- 앱 채점과 복습 일정(기존 `concept_progress`)은 지금 규칙을 유지한다. 틈새 응답은 앱 일정을 바꾸지 않고 '본 조각' 상태와 틈새 카드 순서에만 쓴다. 두 층이 서로의 채점을 덮어쓰지 않게 하려는 것이다.

## 1. 틈새 층 (네이티브, 가장 큰 작업)

1. **조용한 상주 카드 알림.** 기존 `siwc-android` 모듈과 분리된 로컬 모듈 `gap-android`(Kotlin)로 만든다.
   - 소리·진동 없는 기본 중요도 채널, 잠금 화면 공개 표시, `setOnlyAlertOnce`
   - 접힌 상태: 한 줄 문제 + 보기 버튼(OX 2개, 객관식은 펼침에서 3개)
   - 버튼을 누르면 BroadcastReceiver가 앱을 열지 않고 결과를 기록한다. 같은 자리에 "맞았어요/정답은 …" + 한 줄 해설 + '다음' 버튼을 보여 준다.
   - 교체: 응답 후 '다음'을 누르거나, 설정한 간격(15·30·60분)이 지나면 다음 카드로 바뀐다. WorkManager를 쓴다.
   - 표시 시간대(기본 07:00–22:00) 밖이면 카드를 내리고, 시간대가 시작되면 다시 놓는다.
   - 재부팅 후 다시 놓는다(BOOT_COMPLETED).
2. **홈 화면 위젯.** 같은 카드를 위젯으로 보여 준다. 탭으로 응답하며, 민트 띠 모양의 작은 카드다.
3. **JS ↔ 네이티브 연결.**
   - JS가 다음 카드 묶음(약 20장, 정답과 한 줄 해설 포함)과 설정을 네이티브 저장소 파일에 써 둔다.
   - 네이티브는 응답을 이벤트 파일에 적는다.
   - 앱이 열리면 JS가 이벤트를 읽어 SQLite에 반영하고(이벤트 ID로 중복 방지) 카드 묶음을 다시 채운다.
   - 학습 프로필(learner)이 바뀌면 묶음을 비우고 다시 만든다. 다른 프로필의 응답은 버린다.
4. 기존 '복습 호출 알림'(하루 1~3회, 학습하러 오라는 알림)은 **없앤다**. 틈새 카드가 그 역할을 대신한다.

## 2. 앱 층 리디자인 (D안)

**구조.** 탭 4개를 없앤다.

| 경로 | 화면 | 바탕 |
| --- | --- | --- |
| `/` | 온보딩(처음) 또는 **문제 화면** | 어두움 + 틈 |
| `/settings` | 설정 | 밝음(틈이 열림) |
| `/puzzle` | 퍼즐 전체(기존 기록 탭 대체) | 밝음 |
| `/concept/[id]` | 개념 깊게 보기(설명·예시·출처·AI 설명 버튼) | 밝음 |
| `/ai/[id]` | 나에게 맞게 설명 | 밝음 |
| `/auth/return` | 연결 결과 | 밝음 |

규칙: **문제를 풀 때만 어둡고, 나머지는 밝다.** 복습 탭은 따로 두지 않는다. 문제 화면이 복습 차례인 개념을 먼저 꺼낸다.

**문제 화면 상태:** 문제 → 선택 → 확인 → 맞음/틀림 → 다음 … → 오늘 몫 끝. 시안 D의 다섯 장(문제, 답한 뒤, 틀렸을 때, 오늘 끝)을 그대로 구현한다. UI_AUDIT P1-1(오답인데 선택지가 초록으로 남는 문제)은 이 과정에서 해결된다.

**전환.** 설정이나 퍼즐로 갈 때 띠가 위아래로 벌어지는 애니메이션(약 240ms)을 넣는다. 시스템 '애니메이션 줄이기'가 켜져 있으면 바로 전환한다.

**시각 기반.**

- 색 토큰을 새로 정의한다. 어두운 바탕 `#121513`, 띠 `#E8F0EA`, 띠 위 보조 글씨 녹회색 계열, 위험 `#A53332`.
- 글꼴은 Hahmlet(문제·제목)과 IBM Plex Sans KR(본문)이다. `@expo-google-fonts` 패키지로 앱에 넣는다(`npx expo install`).
- 공통 컴포넌트를 새로 만든다: Band(기울어진 띠), OptionRow(선택 시 반전), PuzzleMap, LightScreen, DarkScreen, 버튼, 스위치, 세그먼트

**온보딩.** 어두운 화면과 띠로 3단계를 보여 준다. 두 층 소개 → 하루 문제 수(3/5/10, 기본 5) → 잠금 화면 카드 켜기(알림 권한 요청, 건너뛰기 가능).

**접근성.** 48dp 터치 영역, 200% 글씨, 가로 화면, TalkBack 라벨, 라디오·스위치 역할 표시. 기존 기준을 유지한다.
