# V3 아이디어 정리

2026-10-16. 사용자와 나눈 V3 방향을 정리한 초안이다. 아직 구현 계획이 아니다.

## 한 줄 요약

ChatGPT와 연동한 개인 학습 코치. 무엇을 공부할지 고르면 문제 묶음을 받아 오고, 어디까지 알고 있는지는 조각마다 **해상도**로 관리한다. 오늘 무엇을 할지는 AI가 진행도를 보고 정한다. 처리와 기억은 대부분 기기 안에서 한다.

## 핵심 원칙

- **ChatGPT 연동이 기본이다.** V2에서는 선택 기능이었지만, V3에서는 학습 계획과 대화가 ChatGPT를 전제로 한다.
- **로컬 우선:** 문제 풀이, 채점, 일정, 해상도 계산, 틈새 카드는 기기에서 처리한다. AI는 판단이 필요한 곳(오늘의 계획, 설명, 대화)에만 쓴다.
- **자체 메모리:** 학습 기록, 해상도, 대화, AI가 내린 판단과 그 이유를 앱이 직접 보관한다. ChatGPT의 기존 대화나 메모리를 가져오지 않는다.
- V2의 두 층 구조(틈새 카드 + 앱 문제)와 D안 디자인은 그대로 이어 간다.

## 사용자 흐름

1. **시작:** "어떤 자격증/학습을 할 건가요?"라고 묻는다(예: 정보처리기사, SQLD, 토익 단어 …).
2. **문제 묶음 받기:** 고른 과목의 문제 묶음(개념, 틈새 카드, 앱 문제, 3단계 설명)을 내려받아 기기에 저장한다. *페이퍼 플랜: 실제 서버와 다운로드는 구현하지 않는다. 과제에서는 앱에 포함된 묶음을 "받은 것처럼" 연다.*
3. **매일:** AI가 진행도를 분석해 오늘 띄울 과목·영역·조각을 정한다. 앱 문제와 틈새 카드가 그 계획을 따른다.
4. **막히면:** 설명 글을 끌어 "AI에게 물어보기"로 대화한다(V2.1과 같음). 대화도 메모리에 남아 다음 계획에 반영된다.
5. **퍼즐:** 조각마다 해상도(0~100%)가 있고, 흐릿하던 조각이 공부할수록 선명해진다.

## 해상도 (조각별 이해도)

- 한 번 맞혔다고 100%가 되지 않는다. 시간 간격을 두고, 다른 유형(틈새 O/X, 앱 상황형, 대화 속 설명)으로 반복해서 맞힐수록 올라간다.
- 시간이 지나면 조금씩 흐려진다(망각). 그래서 복습 시점이 자연스럽게 생긴다.
- 100%는 "뇌에 완전히 들어있다"는 상태다. 예를 들면 간격을 둔 서로 다른 유형의 문제를 연속으로 맞힌 경우다.
- 화면 표현: 퍼즐 조각이 흐림·픽셀 상태에서 점점 선명해진다. 퍼즐 화면, 헤더의 퍼즐 지도, 개념 화면에 공통으로 쓴다.

## AI의 하루 계획

기본 아이디어는 AI가 매일 진행도를 분석해 오늘 띄울 과목을 정하는 것이다. 이 부분은 다듬을 여지가 있어 후보를 적어 둔다.

| 방식 | 내용 | 장점 | 단점 |
| --- | --- | --- | --- |
| A. 매일 AI가 전부 결정 | 하루 한 번 진행도 요약을 보내고 오늘의 목록을 받는다 | 가장 단순 | 연결이 끊기면 그날 계획이 없음, 매일 호출 비용 |
| B. AI는 방향, 로컬은 선택 | AI가 주 단위 방향(집중 영역, 비율, 이유)을 정하고, 매일의 구체 조각은 로컬 해상도 계산이 고른다 | 오프라인에서도 동작, 호출이 적음 | 구현이 조금 더 복잡 |
| C. 로컬이 제안, AI가 검토 | 로컬이 후보를 만들고 AI가 순서·설명을 다듬는다 | 결과가 안정적 | AI의 존재감이 약함 |

현재 추천은 **B**다. 그리고 계획에는 항상 짧은 이유를 붙여 보여 준다. 예: "오늘은 데이터베이스 키 조각이 흐려지고 있어서 먼저 띄웠어요." 이것이 "AI가 챙겨 준다"는 느낌을 가장 잘 만든다.

## 기존 메모와의 연결

- 과목 확장: 과목 구분 필드, 과목별 퍼즐, 틈새 카드에 여러 과목을 섞는 방식(오늘의 계획 비율을 따름)
- 해상도 기반 학습 과정과 AI 자동 케어: 위 두 절
- 알림 안쪽 디자인(민트 띠 느낌): V3 전에 해도 되고 V3 디자인과 함께 해도 된다

## 정해야 할 것

1. 과목을 하나씩 고르는지, 여러 과목을 동시에 진행하는지
2. 해상도를 올리고 내리는 구체 규칙(유형별 가중치, 망각 속도)
3. AI 하루 계획 방식(A·B·C 중 무엇)과 계획을 다시 짜는 주기
4. ChatGPT 연결을 시작할 때 필수로 할지, 처음에는 둘러보기를 허용할지
