# V3 구현 계획 — 과목 선택 · 해상도 · AI 7일 계획

2026-10-16. [V3_IDEAS](V3_IDEAS.md)의 결정을 바탕으로 세부를 정했다. 시연용이므로 보여 주기 좋은 쪽을 우선한다. **V3 완료(2026-10-17, `[V3.END]`)** — C1~C5와 아래 8절의 추가 체크포인트(WORK_LOG 참고). 달라진 점: 채팅 '이해했어요' 가산은 넣지 않았고, 문제 화면 대화는 아래에서 올라오는 화면으로 열며, 기존 개념 id는 그대로 둔다.

## 1. 과목 묶음 (페이퍼 다운로드)

- **묶음 형식:** `{ id, title, subtitle, version, areas, concepts, questions }` JSON 하나. 앱에 포함해 두고, 고르면 "받는" 연출(진행 막대 약 1.5초)을 한 뒤 기기 DB에 설치한다.
- **시연용 목록:**
  - 정보처리기사 기초: 지금 콘텐츠 60개, 받을 수 있음
  - SQLD 맛보기: 새로 쓰는 12개, 받을 수 있음. 과목 전환을 보여 주기 위한 작은 묶음
  - 컴퓨터활용능력, 토익 단어: "곧 열려요"로 목록에만 표시
- **한 번에 한 과목:** 설정에서 과목을 바꿀 수 있고, 과목별 기록은 따로 남는다.

## 2. 지식과 해상도

- **지식 단위 = 개념.** 문제마다 `knowledge: [{ id, weight }]`를 둔다(합 1).
  - 틈새 카드: 자기 개념 1.0
  - 앱 문제: 자기 개념 0.7, `builtOn`의 나머지 개념이 0.3을 나눠 가짐
- **해상도 R(0~100) 변화량 = 기본값 × 가중치**
  - 기본값: 틈새 O/X 8, 틈새 객관식 12, 앱 문제 20, 채팅에서 설명을 이해했다고 누름 5
  - 틀리면 같은 크기만큼 내려간다.
- **반감기 H:** V3_IDEAS의 규칙을 따른다. 3일에서 시작하고, 하루 이상 띄운 정답이면 ×2(최대 60), 오답이면 ÷2(최소 1), 바닥은 40%, 100%는 R 95 이상이면서 H 30일 이상. 반감기는 가중치 0.5 이상인 지식만 바뀐다.
- **색 단계(5칸):** 0 / 1~24 / 25~49 / 50~74 / 75~94 / 완전(95 이상 + H 30일 이상). 어두운 화면에서는 `inkLine` → 민트로, 밝은 화면에서는 옅은 잉크 → 잉크로 진해진다. 첫 정답이면 바로 2단계가 되어 성과가 금방 보인다.
- 퍼즐 화면에서 조각을 누르면 "해상도 62% · 반감기 6일"을 보여 준다.

## 3. AI 7일 계획 (B안)

- **요청 내용:** 과목, 지식별 { 해상도, 반감기, 마지막으로 다룬 날 }, 최근 14일 정답률, 지난 계획 달성도, 하루 문제 수
- **응답 형식(JSON):** `{ summary, days: [{ date, focus: [영역 또는 개념 id], newCount, reviewCount, note }] }`. 형식이 맞는지 검사하고, 틀리면 한 번 다시 요청한다.
- **다시 요청하는 때:** 남은 계획이 1일 치가 될 때 자동으로. 그리고 "더 공부하기"로 계획 분량을 다 썼을 때.
- **매일의 문제 고르기(앱):** 오늘 항목의 `focus` 안에서 보이는 해상도가 낮고 반감기상 흐려진 지식을 우선하고, 새 지식은 순서대로 채운다.
- **이유 한 줄:** 문제 화면 띠 아래에 오늘 항목의 `note`를 보여 준다. 예: "오늘은 키 조각이 흐려지고 있어서 먼저 띄웠어요."
- **ChatGPT가 없을 때:** 계획 없이 무작위로 출제한다. 기록은 똑같이 쌓이고, 연결하면 첫 계획을 만든다.
- 퍼즐 화면 맨 위에 이번 계획의 `summary`와 7일 진행 막대를 둔다.

## 4. 문제 화면 채팅 바

- ChatGPT가 연결돼 있으면 문제 화면 맨 아래에 얇은 입력 막대를 둔다.
  - 답하기 전: "힌트 물어보기". AI는 정답을 말하지 않고 힌트만 준다.
  - 답한 뒤: "왜 그런지 물어보기". 문제, 고른 답, 정답, 해설을 맥락으로 함께 보낸다.
- 누르면 아래에서 시트가 올라와 대화한다. 대화는 그 개념의 채팅 기록(V2.1)에 이어 붙는다.

## 5. 화면 흐름 변화

- **온보딩:** 무엇을 공부할까요(과목 목록) → 받기 연출 → 하루 문제 수 → 잠금 화면 카드 → ChatGPT 연결(건너뛰기 가능)
- **설정:** 과목 섹션 추가(지금 과목, 바꾸기)
- **퍼즐:** 해상도 색, 조각 상세, 계획 요약
- 디자인 언어는 D안을 유지한다.

## 6. 데이터

- `subjects`(설치된 묶음), `knowledge_state`(learner·과목·지식별 R, H, 마지막 정답·처리 시각), `plans`(learner·과목별 계획 JSON과 만든 시각)
- 기존 `concept_progress`·`gap_*`·`chat_messages`는 유지하고, 개념 id 앞에 과목을 붙여 과목 간에 겹치지 않게 한다.
