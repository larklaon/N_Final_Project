## 수정 내용

| 항목 | 변경 | 검증 |
| --- | --- | --- |
| R1 삭제 메모리 부활 | 학습자별 개인화 generation을 app_meta에 저장. 삭제/무시 때 증가·진행 중 작업 취소. 추출/승인 전 동일 generation 검사. 그 시점까지 관련 개념/skill의 관찰 ID를 ignored checkpoint로 남김 | 삭제/무시 전 입력·승인 거절, 다음 추출에서 옛 근거 제외, 이후 새 근거 정상 처리, repository 재개 뒤 generation 유지 |
| R2 부적격 확인 재개 | canResumeCheck를 checkSession/openSession/submit에서 공유. 삭제/무시/끄기/숨김이면 일반 문제로 복귀하며 옛 확인 제출도 거절 | 네 경계 모두 재개·제출 차단. 원본·답한 이력 유지. 유효하게 시작한 세션의 단순 만료는 이력 정책대로 완료 허용 |
| R3 대기 AI 동시 시작 | 우선순위 큐에서 선택·슬롯 점유를 동기 처리. 높은 우선순위 먼저, 같으면 FIFO. 대기 취소 즉시 제거. 채팅 선점·자기 ID 취소 유지 | 두 대기 요청의 첫 terminal 전 start 1회, plan 선행·그 뒤 background, 취소 항목 미실행, 늦은 native ID 취소 |
| R4 해설 모순 | 독립 풀이에 생성자 답/해설을 보여 주지 않는 구조 유지. 승인·저장할 **새 문제의 해설은 승인 fact와 적용 조건으로 앱이 구성**. 생성자의 자유 해설은 표시하지 않음 | 의도적으로 넣은 “큐는 후입선출” 해설이 저장/표시용 결과에서 제거되고 FIFO 사실·우선순위 큐 제외 조건이 온전히 포함됨 |
| R5 대화 준비 누락 | 실제 완료된 학습자/assistant 쌍을 저장한 뒤 명시적 입력 이벤트. Runner가 foreground idle을 재예약하고 진행 작업 뒤 대기 활동도 처리 | 첫 idle 이후 새 대화로 추가 준비 1회. user-only·assistant-only는 완료 신호를 만들지 않음. 구독 해제 확인 |

- DB 스키마는 v6 그대로다. 개인화 무효화 값은 기존 app_meta를 사용하고 SQLite 트랜잭션으로 변경한다. 학습 소유권 learningScope와 구분하여 일반 문제의 UI를 불필요하게 초기화하지 않는다.
- R1 무시는 그 메모리의 기존 생성 문제를 hidden으로 만들어, 이후 새 근거로 메모리가 열려도 무시한 옛 카드가 재등장하지 않게 한다. 과거 채점 원본은 보존한다.
- R4는 기존 저장 문제를 재작성하지 않는다. 새 승인 결과의 정책 버전은 v4-2다. fact 문장/적용 조건은 중간에서 자르지 않으며, 표시 길이 안에 들어오는 완전한 사실 단위만 선택한다. 근거 자체의 전문가 검수나 모든 생성 정답의 진실 보증을 의미하지 않는다.
- 추가 AI 호출은 없다. 자동 준비 1회 최대 3회, 기존 배포/개발 빌드 규칙과 일일 한도를 유지한다.
- R3 타임아웃/취소 때 native start promise가 늦어도 슬롯 대기가 끝날 수 있게 제한 시간을 두고, 나중에 온 ID는 그 ID만 취소한다. 테스트의 terminal 미발신 모의 gateway는 fake timer로 정리하여 열린 타이머 경고도 제거했다.

## 큰 글씨·세로 고정 검사

이전 0/4 실패는 오늘 목표 5/5 완료 화면을 문제 화면으로 가정한 데서 나왔다. 1/4 실패에서는 스크롤 제스처가 중첩 가로 코드 뷰 위에서 시작하고 scroll() false 반환 직후 검사가 끝났다.

LayoutTest를 다음처럼 수정했다.

1. 이미 하루 목표가 끝났으면 “조금 더 풀기”에 진입해 실제 보기가 나타날 때까지 대기한다. 답은 제출하지 않는다.
2. 세로 ScrollView를 선택하고 가로 코드 영역 바깥의 본문 여백에서 실제 위로 스와이프한다. scroll()의 접근성 반환값만으로 검사를 중단하지 않는다.
3. 각 선택지의 누적 도달, 최소 48dp 노출, 기본 버튼·설정 노출 및 세로 유지 단언은 그대로 둔다.

**API36: 360dp/글씨200% 22.279초, 가로 방향 요청 후 세로 고정 19.007초에 각각 OK(1 test).** 새 캡처에서 네 선택지가 보임을 확인했다. 앱의 시각 배치 코드는 바꾸지 않았다. 검사 후 font1.0, density420(override 없음), 자동회전1, user_rotation0으로 복원했다. 연습 세션 진입 외에 정답 제출·기록 초기화·개인화 설정 변경은 하지 않았다.
