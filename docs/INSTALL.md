# 틈지식 설치 가이드 (시연용 APK)

## 준비

- Android 8.0 이상 휴대폰(대부분의 최근 폰, arm64)
- APK 파일: `teum-knowledge-0.1.0-demo-arm64.apk`
- AI 기능을 보여 줄 경우: ChatGPT 계정(플랜 사용 가능 계정)

## 설치

1. APK 파일을 폰으로 옮긴다(카카오톡·드라이브·USB 등).
2. 폰에서 파일을 연다.
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켜고 돌아온다.
4. **설치**를 누른다. Play 프로텍트 경고가 나오면 **무시하고 설치**(또는 세부정보 → 설치)를 고른다.
5. **열기**를 누른다.

## 첫 실행

6. 온보딩을 따라간다: 과목 받기 → 하루 문제 수 → 잠금 화면 카드(**카드 켜기** → 알림 **허용**) → AI 코치.
7. ChatGPT 연결: 온보딩의 **ChatGPT 연결하기**(건너뛰었다면 설정(⋯) → **Continue with ChatGPT**) → 안내에 동의 → 브라우저에서 로그인 → 앱으로 돌아오면 설정에 "ChatGPT 플랜 사용 가능".
8. AI 맞춤 학습: 설정 → "AI 학습 정보 전송 동의"가 켜져 있는지 확인 → **AI 맞춤 학습** 켜기.
9. (선택) 위젯: 설정 → **홈 화면에 위젯 놓기** → 추가.

## 시연 흐름 (약 5분)

10. 개념 화면 → **AI에게 물어보기**에서 헷갈린 생각을 한 문장으로 보낸다(예: "큐도 스택처럼 나중에 넣은 게 먼저 나오는 거죠").
11. 앱을 켜 둔 채 30초쯤 기다린 뒤, 그 개념 화면 아래 **자주 헷갈린 점 `AI`**를 확인한다.
12. 위젯이나 잠금 화면에 뜬 **AI 카드**(영역 옆 "· AI")에 답한다.
13. 1분쯤 뒤 문제 화면에 **AI 확인 문제**가 나온다. 맞히면 '나아지는 중', 다른 확인 문제를 한 번 더 맞히면 '이젠 맞혀요'.

## 알아둘 것

- 시연용 빌드는 AI 맞춤 학습의 대기 시간과 하루 한도만 줄였다. 실제 규칙은 카드에 답하고 24시간 뒤·다른 날짜에 확인 문제가 나온다.
- 새 APK는 지우지 않고 덮어 설치하면 기록이 남는다. 앱을 삭제하면 기록도 함께 지워진다.
- 학습 기록은 폰 안에만 저장된다. AI를 쓸 때만 OpenAI로 내용이 전송된다.
- 잠금 화면 카드는 설정의 **방해 금지 시간**(기본 22:00–07:00)에는 뜨지 않는다. 시연 시간이 겹치면 방해 금지를 끈다.
