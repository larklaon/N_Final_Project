# 틈지식 발표 자료 원고

대상: 프로젝트 결과 소개. 화면용 자료는 [발표용 PPTX](../presentation/teum-knowledge-course-project.pptx)에 있다. 아래 문장은 발표자가 설명할 근거와 순서를 남긴다.

## 1. 틈지식

잠깐의 틈에 기초 개념을 만나고, 앱을 열면 그 개념을 한 단계 깊게 푼다. Android 개인 프로젝트이며 현재 V4 시연용 APK까지 만들었다.

## 2. 해결하려는 문제

대상은 정보처리기사·SQLD 기초를 시작하려는 사람이다. 긴 학습 시간을 매일 내기 어렵다는 문제 가설에 맞춰, 앱을 열지 않을 때는 아주 짧은 카드로 개념을 접하고 앱 안에서는 상황형 문제로 확인하도록 설계했다. 학습 효과의 크기는 아직 검증하지 않았다.

## 3. 두 층의 경험

잠금 화면 O/X와 홈 위젯은 준비된 덱에서 카드를 보여 준다. 앱은 하루 3·5·10문제, 다시 풀기, 개념 설명과 해상도 퍼즐을 제공한다. 기본 콘텐츠는 72개념·144틈새 카드·72앱 문제다. 무음·방해 금지 시간·알림 권한 선택을 존중한다.

## 4. AI가 맡는 일

SIWC 연결과 전송 동의가 있으면 질문·힌트·해설·7일 계획을 쓴다. AI 맞춤 학습을 별도로 켜면 오답과 완료된 앱 대화에서 헷갈린 점을 추출하고, 승인된 기준 사실을 바탕으로 O/X 카드와 확인 문제를 만든다. 정답 판정과 일정 계산은 앱 규칙이다.

## 5. 두 기술 요소

Long-term Memory는 근거가 있는 헷갈림 상태를 SQLite에 저장하고 다음 카드와 계획에 활용한다. 자동화 워크플로우는 기록 수집, AI 추출·생성·별도 검토, 네이티브 덱 편입, 응답 수집, 확인 문제와 메모리 갱신을 연결한다. 기기 밖의 AI 호출은 앱이 앞에 있고 사용자 동의가 유효할 때만 한다.

## 6. 구조와 안전장치

React Native/Expo는 학습 화면을, Kotlin 모듈 두 개는 SIWC 인증·추론과 Android 잠금 화면·위젯을 맡는다. SQLite가 학습 기록 기준이다. 토큰은 Android Keystore 보호 저장소에 두고, 중복 응답은 이벤트 ID와 트랜잭션으로 막는다. AI 생성물은 `AI`로 표시하고 근거·숨기기·삭제를 제공한다. 자동 검토는 전문가 검수를 뜻하지 않는다.

## 7. 구현과 검증

V4 이후 최종 검수 5건을 재현하고 수정했다. 온보딩 연결·화면 가장자리 후속 수정 뒤 Jest 158개, lint·타입 검사가 통과했다([WORK_LOG](WORK_LOG.md)). 이전 검증에는 Kotlin/JUnit SIWC 35개·틈새 17개, API36 화면 크기·글씨 확대 검사와 실제 계정 AI 흐름 확인이 있다. 각 숫자는 수행 시점의 기록이며 최신 APK 전체를 같은 범위로 다시 검증했다는 뜻은 아니다.

## 8. 시연과 현재 경계

시연: 과목 받기 → 잠금 화면 카드·위젯 → 앱 문제 → ChatGPT 연결·맞춤 학습 → 헷갈림·AI 카드 → 확인 문제. 개인 프로젝트에서 기획, 화면과 Kotlin 모듈 구현, 자동 검증, APK 제작과 기술 문서화를 수행했다. 시연용 arm64 APK는 Metro 없이 에뮬레이터에서 실행했다. 맞춤 학습의 대기 시간·일일 한도는 시연을 위해 줄였다. APK 외부 다운로드 링크는 아직 없다. 신규 계정 인증·물리 기기별 동작·전체 콘텐츠 전문가 검수는 별도 확인이 필요하다.
