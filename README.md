# 틈지식

정보처리기사의 기초 개념을 짧게 익히는 Android 앱입니다. React Native · Expo SDK 57 · TypeScript를 사용합니다.

## 개발

Node 24 LTS에서 `npm ci`, `npm run check`, `npm start`로 준비합니다. Android 실행은 JDK 17과 Android SDK 36을 설치한 뒤 `npm run android`를 사용합니다. SIWC는 Kotlin 로컬 모듈을 사용하므로 Expo Go 대신 Development Build가 필요합니다.

현재 구현과 검증 결과는 [작업 기록](docs/WORK_LOG.md), 인증 상태는 [SIWC 상태](docs/SIWC_STATUS.md)를 확인하세요.
