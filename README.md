# 틈지식

정보처리기사 공부를 시작하기 전, 기초 개념을 짧게 익히고 반복하는 Android 학습 앱입니다. React Native + Expo Development Build로 개발한 로컬 우선 MVP입니다.

## 구현 기능

공부하는 앱이 아니라 **공부한다고 착각하는 앱**이다. 두 층으로 동작한다.

- **틈새 층:** 잠금 화면에 소리·진동 없이 놓이는 카드와 홈 위젯이다. 아주 쉬운 O/X·객관식이고, 앱을 열지 않고 탭 한 번으로 답한다. 응답은 학습 기록에 남는다.
- **앱 층:** 앱을 열면 문제 하나만 보인다. 어두운 화면 사이 밝은 띠(틈) 안에 한 단계 깊은 상황형 문제가 있다. 하루 3·5·10문제.
- **퍼즐:** 틈새에서 본 조각과 앱에서 맞춘 조각을 영역별로 보여 준다. 앱 문제가 틈새에서 본 조각을 쓰면 알려 준다.
- 정보처리기사 기초 6개 영역의 개념 60개, 틈새 카드 120장, 앱 심화 문제 60개. 콘텐츠는 **AI 작성 초안**이며 개별 출처 대조·전문가 검수 전이다.
- SQLite 학습 기록, 중복 채점 방지, 두 층의 간격 복습, 프로필별 기록 분리, 기록 초기화와 전체 삭제
- SIWC Kotlin 인증·토큰 보호·스트리밍, 학습 이력을 반영한 AI 설명(선택)

실제 ChatGPT 계정의 OAuth 로그인과 AI 응답은 아직 미검증이다. 기본 학습에는 ChatGPT 구독이나 AI 연결이 필요하지 않다.

## 실행

Node 24 LTS, JDK 17, Android SDK 36을 준비합니다.

```sh
npm ci
npm run check
npx expo prebuild --platform android
npm run android
```

인증용 로컬 Kotlin 모듈이 있으므로 **Expo Go에서 SIWC를 검증할 수 없습니다.** 개발용 APK에는 Metro 서버가 필요합니다. 빌드 프로필과 도구 설정은 [BUILD](docs/BUILD.md)를 확인하세요.

## 틈새 카드와 알림

학습하러 오라고 부르는 알림은 보내지 않는다. 잠금 화면 카드는 온보딩이나 설정에서 켜며 알림 권한이 필요하다. 카드가 바뀌는 간격(15·30·60분)과 시간대를 고를 수 있다. 절전·강제 중지 상태에서는 교체가 늦어지거나 멈출 수 있다. 위젯은 설정의 '홈 화면에 위젯 놓기'나 런처에서 추가한다.

인증 토큰은 JS·SQLite로 전달하지 않고 Android Keystore로 보호한다. 구조는 [ARCHITECTURE](docs/ARCHITECTURE.md)를 본다.
