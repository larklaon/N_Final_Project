# 틈지식

자격증 공부를 시작하기 전, 기초 개념을 틈틈이 스치고 맞춰 가는 Android 학습 앱입니다. React Native + Expo Development Build로 개발한 로컬 우선 앱이며, 현재 V3까지 구현되어 있습니다. 휴대폰 앱은 세로 화면으로 고정됩니다.

## 구현 기능

공부하는 앱이 아니라 **공부한다고 착각하는 앱**이다. 두 층으로 동작한다.

- **틈새 층:** 잠금 화면에 소리·진동 없이 놓이는 O/X 카드(두 줄에 맞춘 짧은 문장)와 홈 위젯. 위젯은 크기에 따라 O/X·용어 맞히기 4지선다·3지선다를 돌아가며 낸다. 앱을 열지 않고 탭 한 번으로 답하고, 응답은 학습 기록에 남는다.
- **앱 층:** 앱을 열면 문제 하나만 보인다. 어두운 화면 사이 밝은 띠(틈) 안에 한 단계 깊은 상황형 문제가 있다. 하루 3·5·10문제. 문제가 기댄 "스친 조각"을 누르면 그 카드를 다시 풀 수 있다.
- **과목:** 정보처리기사 기초(60조각)와 SQLD 맛보기(12조각)를 받아 한 번에 하나씩 공부한다. 과목별 기록은 따로 남는다.
- **해상도:** 지식마다 0–100%와 반감기가 있어 맞히면 진해지고 시간이 지나면 흐려진다. 퍼즐 화면과 조각 색(연민트 → 진한 민트)으로 보인다.
- **AI (ChatGPT 연결 시, 선택):** 해상도를 보고 7일 계획을 짜 출제 순서를 정하고, 문제의 힌트·왜 그런지, 개념 본문 일부를 끌어 와 묻기, 개념별 대화 기록. 연결하지 않으면 문제는 무작위로 나온다.
- SQLite 학습 기록, 중복 채점 방지, 두 층의 간격 복습, 프로필별 기록 분리, 기록 초기화와 전체 삭제
- SIWC Kotlin 인증·토큰 보호·스트리밍. 구독 사용량은 ChatGPT 공식 페이지를 앱 안 브라우저로 연다.

콘텐츠는 **AI 작성 초안**이며 개별 출처 대조·전문가 검수 전이다. 기본 학습에는 ChatGPT 구독이나 AI 연결이 필요하지 않다.

## 실행

Node 24 LTS, JDK 17, Android SDK 36을 준비합니다.

```sh
npm ci
npm run check
npx expo prebuild --platform android
npm run android
```

인증용 로컬 Kotlin 모듈이 있으므로 **Expo Go에서 SIWC를 검증할 수 없습니다.** 개발용 APK에는 Metro 서버가 필요합니다. 빌드 프로필과 도구 설정은 [BUILD](docs/BUILD.md)를 확인하세요.

## 틈새 카드와 알림

학습하러 오라고 부르는 알림은 보내지 않는다. 잠금 화면 카드는 온보딩이나 설정에서 켜며 알림 권한이 필요하다. 카드가 바뀌는 간격(15·30·60분)을 고르고, 카드를 보여 줄 시간대는 시·분 휠로 자유롭게 정한다. 절전·강제 중지 상태에서는 교체가 늦어지거나 멈출 수 있다. 위젯은 설정의 '홈 화면에 위젯 놓기'나 런처에서 추가한다.

인증 토큰은 JS·SQLite로 전달하지 않고 Android Keystore로 보호한다. 구조는 [ARCHITECTURE](docs/ARCHITECTURE.md)를 본다.
